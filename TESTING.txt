아코 노트 테스트 계획 — 2026-11-07

목적
금액 계산 오류, 데이터 유실, 중복 반복 거래, 잘못된 복원 및 화면 간 조회 불일치를 방지한다.

1. 단위 테스트 (Node.js test runner)
대상: core/domain.js, core/backup.js.
정상값과 경계값: 날짜 윤년·월말·연도 전환, 1~999999999원 정수, 0원 예산,
환불 합계·기간 귀속·수정 제한, 카테고리/결제수단 연결, 날짜별 저축 잔액,
반복 종료일·같은 날 설정 변경·중지/재개·건너뜀·삭제, 정확한 큰 금액 합계.
백업: 왕복, 필드 누락/추가, 중복 ID/JSON 키, 잘못된 참조, 타입, 버전,
UUID 및 UTC 시각 형식, JSON 문법과 중첩 제한.
테스트는 고정 날짜와 독립 상태를 사용한다. 오류가 예상되면 해당 오류까지 확인한다.

2. 저장소 통합 테스트 (fake-indexeddb)
대상: 도메인 검증 + 저장소 트랜잭션 + 백업 복원.
최초 초기화/재실행, 관련 테이블 동시 저장, 검증 실패 및 쓰기 중 예외의 전체 롤백,
동일 변경 토큰의 경합, 전체 복원 후 세대 변경과 이전 초안 거부,
잘못된 복원 시 현재 데이터/복구 사본 유지, 재실행/도래 처리의 멱등성.
각 테스트에서 DB를 새로 만들고 연결을 닫는다. 브로드캐스트는 이 층에서 제외한다.

3. 브라우저 통합/E2E (Playwright + 설치된 Edge)
실제 브라우저 IndexedDB와 DOM을 사용하며 새 브라우저 컨텍스트로 사용자 데이터와 격리한다.
기존 거래/환불/예산/저축, 검색/필터/통계, 다중 탭, 저장 실패, 백업/복원,
PWA 오프라인 및 사용성 회귀를 유지한다.
추가: 실제 DB의 복원 세대 충돌과 쓰기 중 롤백, 반복 거래 재실행 처리,
화면에서 카테고리 보관/복원 및 예산 복사 연결.
무저장 preview.html 테스트는 퍼블리싱 회귀이며 저장 기능 통합과 구분한다.

실행 순서
npm.cmd run check
npm.cmd run test:unit
npm.cmd run test:integration
npm.cmd run test:browser (실제 앱 18개만 실행)
npm.cmd run test:ui
npm.cmd run test:coverage

npm.cmd test로 구문 검사와 모든 테스트를 한 번에 실행할 수 있다.

통과 기준
모든 필수 테스트 통과, 테스트 중 예상하지 않은 스크립트 오류 없음.
실패는 재현 테스트를 남기고 원인 수정 후 관련 테스트와 전체 회귀를 실행한다.
커버리지는 빈 구간을 찾는 보조 자료이며 높은 수치만으로 완료를 판단하지 않는다.

범위의 한계
fake-indexeddb는 브라우저의 디스크/저장공간 정책을 완전히 대체하지 않는다.
Edge 통합으로 보완하되 Safari/Firefox, 실제 모바일 설치와 OS 한글 IME는 실기 검증 대상이다.
실제 사용자 데이터, 외부 결제/카드 연동, 서버/계정/동기화는 사용하지 않는다.

실행 결과는 artifacts/tests/에 기록한다.
