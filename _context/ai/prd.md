# acco-note AI 제안 요구사항 (초안)

> 아래 항목은 사용자 확정 요구사항이 아닌 **AI 제안**입니다. 사용자 확인 전까지 `_context/user/prd.md`의 요구사항으로 간주하지 않습니다.

## 우선순위 높음 — 기본 사용성

### A-01. 거래 내역 CRUD 및 입력 필드
- 지출/수입 내역을 작성, 수정, 삭제할 수 있도록 합니다.
- 기본 필드 후보: 거래일, 유형(지출/수입), 금액, 내역명, 카테고리, 메모, 결제수단(지출에 적용).
- 금액 유효성 검사, 입력 누락 및 삭제 확인 등의 UI를 제공합니다.
- **결정 필요:** 필수 필드 범위, 결제수단 미선택 허용 여부, 과거/미래 날짜 입력 제한 여부.

### A-02. 카테고리 관리
- 지출 및 수입 카테고리를 분리해 관리하고, 거래 내역에 연결합니다.
- 기본 카테고리를 제공하되 사용자 정의 카테고리를 추가/수정/삭제할 수 있도록 제안합니다.
- 카테고리별 합계와 비중을 조회할 수 있도록 제안합니다.
- **결정 필요:** 카테고리 삭제 시 기존 내역 처리, 복수 단계(상위/하위) 분류 필요 여부.

### A-03. 결제수단 관리 확장
- 사용자가 결제수단(카드별 별칭, 현금, 계좌이체, 간편결제 등)을 직접 추가/수정/삭제하도록 제안합니다.
- 지출 작성 시 결제수단을 선택하고, 기간별 사용액/사용 횟수/비중을 집계합니다.
- 카드 사용의 **기록과 분석**이 목적이며 카드 연동/실제 결제 처리는 제외합니다.
- **결정 필요:** 카드별 별칭과 유형의 구분, 결제수단 삭제 시 기존 내역 처리, 수입의 결제수단 선택 여부.

### A-04. 날짜 기반 탐색 및 검색·필터
- 달력과 목록에서 날짜를 탐색하고, 날짜별 내역 및 합계를 확인합니다.
- 기간, 수입/지출, 카테고리, 결제수단, 키워드로 필터링할 수 있도록 제안합니다.
- **결정 필요:** 기본 진입 화면(달력/목록/대시보드).

## 우선순위 중간 — 재무 관리 및 분석

### A-05. 예산 관리
- 월별 총지출 예산 또는 카테고리별 예산을 설정하고, 사용액/잔여액/초과액을 표시합니다.
- 기존 '목표 설정'과의 관계를 정의해야 합니다.
- **결정 필요:** 목표가 저축 목표인지 지출 상한(예산)인지, 둘 다 필요한지.

### A-06. 통계·비교 분석
- 기간별 총수입, 총지출, 차액을 요약합니다.
- 일/주/월 추이와 직전 기간 비교, 카테고리별·결제수단별 비중을 제공합니다.
- **결정 필요:** 주 시작 요일, 차트 종류, 비교 기준과 집계 제외 규칙.

### A-07. 고정지출의 실제 반영 방식
- 반복 규칙(매월 N일 등)과 예상 지출을 별도 목록으로 관리합니다.
- 달력에 표시되는 **예정 항목**과 집계에 반영되는 **실제 거래 내역**을 구분할 것을 제안합니다.
- **결정 필요:** 수동 확인 후 등록 vs 자동 등록, 미발생/금액 변동/말일 처리 방식.

## 우선순위 높음 — 로컬 데이터 안전성

### A-08. 내보내기·가져오기 검증 및 복구
- JSON 내보내기에 데이터 형식 버전(schemaVersion)을 포함합니다.
- 가져오기 시 파일 구조 검증, 오류 안내, 덮어쓰기/병합 정책과 미리보기를 고려합니다.
- 브라우저 저장 데이터 삭제 및 기기 변경 시 데이터 유실 가능성을 안내합니다.
- **결정 필요:** Import 시 전체 대체 vs 병합, 충돌 처리 방식, 백업 리마인더 필요 여부.

## 추후 검토

### A-09. 계좌 간 이체/카드대금 이중 집계 방지
- 결제수단별 지출 기록에 계좌 이동이나 카드대금 납부까지 포함할 경우 지출 중복 집계를 방지할 정책이 필요합니다.
- 초기 버전에서 자산/계좌 잔액 추적 및 이체를 지원할지 결정합니다.

### A-10. 접근성·사용성
- 모바일 화면 대응, 키보드 입력, 금액 입력 UX, 빈 상태와 오류 안내를 고려합니다.
- 별도 서버가 없는 환경에서의 오프라인 사용 범위 및 PWA 제공 여부는 추후 검토합니다.

## 초기 논의 우선 질문

1. 목표는 **월 지출 예산**, **저축 목표**, 또는 둘 다를 의미하나요?
2. 고정지출은 해당 날짜에 **예정으로만 표시**하나요, 아니면 **자동으로 실제 지출에 포함**하나요?
3. 결제수단은 카드별로 구분하되 **카드대금 납부/계좌 잔액 관리**까지 할 필요가 있나요?
4. JSON Import는 기존 데이터를 **대체**하나요, **병합**하나요?
