# acco-note 화면 상세 정의서

이 문서는 [기능 정의](functions.md), [사용자 흐름](user-flows.md), [확정 정책](policies.md)을 화면으로 구체화합니다. 저장 구조는 [데이터 정의서](data-model.md)를 따릅니다. 화면 ID는 구현과 검증에서 유지합니다. 실제 UI 구현이나 시각 디자인 완료를 의미하지 않습니다. PWA는 보류합니다.

최신 퍼블리싱 변경: 화면을 덮는 모달·백드롭을 제거합니다. 아래의 상세 패널·확인 대화상자는 현재 UI에서 목록 또는 관련 페이지 안에 펼치는 비모달 영역으로 표현합니다. 내역 추가는 목록 맨 위 입력 행으로 표시하며 날짜·수입/지출·내역명·금액·카테고리·결제수단 순서, 접힌 메모, 추가/취소 버튼으로 구성합니다. 모바일에서는 같은 입력 행을 여러 줄로 배치합니다. 실제 저장 기능은 연결하지 않았고 추가 미리보기 후 입력 행을 유지합니다.

내역 목록은 날짜·유형·내역명·금액·카테고리·결제수단·상세 열을 가진 표로 표시합니다. 모바일에서는 날짜·내역명·금액·상세만 표시하고 나머지는 행 아래 펼친 상세에서 확인합니다. 상세는 큰 아이콘·금액 강조 카드 대신 간격을 줄인 항목/값 표와 수정·삭제·환불 버튼으로 구성합니다.

상세의 제목·닫기 X·별도 환불 영역을 제거하고 상태·분류·결제수단·메모만 압축해서 표시합니다. 같은 행을 다시 누르면 접고 다른 행을 누르면 상세를 전환합니다. 하단 동작 순서는 삭제·수정·환불이며 수입에는 환불을 표시하지 않습니다. 툴바의 보기 전환 오른쪽 휴지통은 선택 모드로 전환합니다. 각 행과 전체 선택 체크박스, 선택 건수, 선택 삭제·취소를 제공하고 삭제 전 인라인 확인을 거칩니다. 현재 샘플 삭제는 화면 메모리에만 반영하고 새로고침하면 복원합니다.

## 1. 탐색과 공통 배치

| 탐색 영역 | 화면 | 주요 기능 |
| --- | --- | --- |
| 내역 | S-01 내역·달력, S-02 거래 상세, S-03 거래 입력, S-04 환불 입력, S-05 통계 | F-01~F-03, F-07, F-10 |
| 예산 | S-06 월 예산, S-07 예산 설정·복사 | F-08 |
| 저축 | S-08 목표 목록, S-09 목표 상세, S-10 목표·기록 입력 | F-09 |
| 관리 | S-11 관리 홈, S-12 고정지출 목록·상세, S-13 반복 입력, S-14 분류·결제수단, S-15 백업·복원 | F-04~F-06, F-11~F-12 |
| 공통 | S-00 첫 실행·저장소 확인, D-01 확인 대화상자 | 전체 |

앱을 열면 S-01의 이번 달 목록을 표시합니다. 목록/달력 선호는 저장하되 진입 월은 항상 이번 달입니다. 통계는 내역 안의 보조 탭이며 별도 대시보드는 만들지 않습니다. 관리 홈은 고정지출·카테고리·결제수단·백업으로 연결합니다.

| 화면 너비 | 탐색 | 목록·상세·입력 |
| --- | --- | --- |
| 320~767px | 하단 4개 탐색 | 단일 열. 상세·입력은 별도 화면, 필터는 펼침 영역 |
| 768~1199px | 왼쪽 탐색 | 단일 본문, 상세·입력은 본문 전환 |
| 1200px 이상 | 왼쪽 탐색 | 목록과 상세 두 열. 입력은 오른쪽 단일 열 패널 |

모바일 입력 화면에서는 하단 탐색을 숨기고 상단 뒤로·제목과 하단 취소·저장을 표시합니다. 가상 키보드가 떠도 입력과 저장으로 접근할 수 있도록 스크롤 여백을 확보합니다. 데스크톱 패널을 닫거나 모바일 뒤로가기를 하면 이전 필터·선택 기간·스크롤 위치로 돌아갑니다. 크기 전환은 같은 편집 상태를 재배치하며 입력을 초기화하지 않습니다.

```text

│ 내역 / 통계          │            │ 예산 │ 수입·순지출·차액    │ 내역명·금액    │
│ 수입 / 순지출 / 차액 │            │ 저축 │ 검색·필터·보기 전환 │ 날짜·분류·수단 │
│ 예정 수입 / 예정 지출│            │ 관리 │ 날짜별 거래 목록    │ 연결 환불      │
│ 검색  필터  목록/달력│            │      │                     │ 수정·환불·삭제 │
│ 날짜별 내역          │            └──────┴─────────────────────┴────────────────┘
│ + 거래 추가          │
│ 내역  예산  저축 관리│
└──────────────────────┘
```

## 2. 공통 상태와 조작 규칙

| 상태 | 표시·동작 |
| --- | --- |
| 초기 로딩 | 제목과 로딩 표시. 데이터 확인 전 '0원'이나 '내역 없음'으로 단정하지 않음 |
| 비어 있음 | 설명과 관련 추가 버튼. 예: '아직 기록한 내역이 없어요' + 거래 추가 |
| 검색 결과 없음 | '조건에 맞는 내역이 없어요' + 필터 초기화. 기존 데이터 삭제로 표현하지 않음 |
| 입력 검증 오류 | 필드 아래 이유, 첫 오류로 포커스 이동, 입력 유지. 입력 중에는 과도한 오류를 띄우지 않고 저장 시 전체 검증 |
| 저장 중 | 저장·삭제 재실행 차단, 진행 표시. 성공 전 목록·집계는 확정 변경하지 않음 |
| 저장 실패 | '저장하지 못했어요'와 재시도. 입력·기존 기록 유지. 저장 공간 문제이면 백업 이동 제공 |
| 다른 탭 변경 | 입력 유지, '다른 탭에서 변경됐어요'와 최신 내용 확인. 자동 덮어쓰기 금지 |
| 삭제된 대상·복원으로 사라진 대상 | 상세를 오래된 데이터로 계속 편집하지 않고 목록 복귀 안내. 편집 내용은 복사할 수 있게 유지 |
| 성공 | 저장 완료 안내 후 상세/목록 갱신. 스크린리더에도 상태 전달 |
| 미저장 이탈 | D-01에서 계속 작성 / 변경 버리고 나가기. 브라우저 종료는 가능한 기본 경고 사용 |

모든 입력에는 레이블과 필수/선택 표시를 제공합니다. 금액은 원 단위로 표시하고 수입·지출·환불을 부호와 텍스트로 함께 구분합니다. 터치 영역은 최소 44×44 CSS px입니다. 대화상자는 초점을 내부에 유지하고 닫은 뒤 호출한 버튼으로 복귀합니다. 파괴적 확인의 기본 초점은 취소에 둡니다.

## 3. S-00 — 첫 실행과 저장소 확인

- 진입: 앱 시작. 저장소 열기·스키마 확인 후 기본 카테고리 초기화와 도래 거래 확정을 수행합니다.
- 최초 안내: '이 브라우저에만 저장됩니다', 기기 동기화 없음, 브라우저 데이터 삭제 전 JSON 내보내기 필요. '시작하기' 후 S-01로 이동합니다. 안내 확인 여부는 로컬 설정에 저장합니다.
- 저장소 사용 불가: 원인을 표시하고 재시도합니다. 저장 가능한 것처럼 빈 가계부를 띄우지 않습니다.
- 도래 거래 처리 실패: 실패 상태를 명시하고 재시도합니다. 완료되지 않은 집계를 최신 확정 결과로 표시하지 않습니다.
- PWA 설치·서비스 워커 등록·오프라인 재실행 보장 안내는 제공하지 않습니다.

## 4. S-01 — 내역 목록과 달력

**진입:** 앱 기본 화면, 예산/통계의 내역 보기, 저장 후 복귀. **데이터:** 거래·환불·반복 예정 투영·분류·결제수단.

- 상단: 일/주/월/기간 선택, 이전·다음, 오늘, 목록/달력 전환, 거래 추가. 사용자 지정 기간에는 시작·종료일을 표시합니다.
- 요약: 전체 선택 기간의 총수입·순지출·차액·환불액. 예정 수입과 예정 지출은 별도 행입니다. 검색·필터가 있으면 '필터 결과 합계'를 추가하고 기간 전체 요약과 구분합니다.
- 퍼블리싱 화면 조정: 내역 상단 요약은 이번 달 지출·남은 금액(수입−지출)·남은 예산 순서입니다. 수입 요약 카드는 표시하지 않습니다. 남은 예산은 남은 금액 옆에 배치하며 별도 예산 카드와 '곧 나갈 돈' 사이드 카드는 제거합니다. 수입 거래와 예산 기능 자체는 유지합니다.
- 검색: 내역명·메모 입력 후 Enter 또는 검색 버튼으로 적용. 필터는 유형·카테고리·결제수단·상태와 초기화입니다. 보관 분류도 과거 조회 조건으로 선택할 수 있고 미분류·미선택도 선택 가능합니다.
- 상태: 확정 필터에는 환불을 포함합니다. 예정에는 일반·고정지출 예정이 포함되고 건너뜀은 명시적으로 선택할 때만 표시합니다. 유형 수입만 선택하면 환불은 표시하지 않습니다.
- 목록: 날짜 내림차순, 같은 날 생성 시각 내림차순·ID 순으로 안정 정렬합니다. 각 행은 내역명·금액·유형/상태·분류·결제수단을 표시합니다. 메모는 한 줄 미리보기입니다. 날짜 그룹에 확정 수입·순지출과 별도 예정액을 표시합니다.
- 환불 행: '환불 · 원거래명', 환불일·금액. 선택하면 S-02 원거래 상세의 해당 환불로 이동합니다. 선택 기간 밖 원거래도 상세에서 볼 수 있습니다.
- 예정 회차 선택: 아직 저장되지 않은 계산상 회차도 S-02에서 확인하고 수정·건너뛰기할 수 있습니다. 조회만으로 거래를 생성하지 않습니다.
- 달력: 월요일 시작, 날짜 셀에 확정 수입/순지출·예정 표식. 모바일은 셀에는 축약 금액을 사용하고 날짜 선택 시 아래 목록에서 정확한 금액·내역을 제공합니다. 필터는 목록과 동일하게 적용합니다.
- 완료: 편집 후 동일 조건으로 돌아오며 조건에서 벗어난 거래는 '변경되어 현재 조건에서 제외됐어요'를 안내하고 목록에서 빠집니다.

## 5. S-02 — 거래 상세

- 상단: 내역명·유형·상태·금액·거래일. 본문: 카테고리·결제수단·메모, 고정지출이면 반복 이름·원래 회차일·개별 수정 표시와 반복 상세 이동.
- 확정 지출: 수정, 삭제, 환불 기록. 환불 합계·남은 환불 가능액·각 환불일/금액/메모와 수정·삭제를 표시합니다. 남은 금액이 0이면 추가 환불은 비활성화하고 이유를 설명합니다.
- 수입·예정: 환불 버튼을 제공하지 않습니다. 예정 고정지출은 건너뛰기, 확정 생성 거래는 삭제 시 건너뜀 전환을 안내합니다.
- 건너뜀 회차: 거래가 존재하는 것처럼 표시하지 않고 보존된 예정 정보와 건너뜀 취소를 제공합니다. 삭제된 반복 또는 중지 기간 등 복원 불가 조건이면 이유를 표시합니다.
- 원거래 삭제: D-01에 원거래 금액, 연결 환불 건수·합계, 관련 기간 집계 변경과 회차 건너뜀 여부를 표시합니다. 취소하면 모두 유지합니다.
- 환불만 삭제: '원거래는 유지됩니다. 해당 환불의 차감이 취소됩니다'를 안내합니다.

## 6. S-03 — 거래 등록·수정

| 순서 | 필드 | 기본·제약 |
| --- | --- | --- |
| 1 | 수입/지출 | 신규는 지출, 편집은 기존 값. 고정지출은 지출 고정 |
| 2 | 날짜 | 신규 오늘, 유효한 날짜 필수. 미래면 '예정으로 저장' 안내 |
| 3 | 금액 | 필수, 1~999,999,999원 정수 |
| 4 | 내역명 | 필수, 공백 제거 후 1~100자 |
| 5 | 카테고리 | 선택, 유형에 맞는 활성 항목. 기존 보관 연결은 표시·유지 가능 |
| 6 | 결제수단 | 지출일 때만 표시, 선택. 신규 선택에 보관 항목 제외 |
| 7 | 메모 | 선택, 최대 1,000자와 글자 수 |

유형 변경 시 해제될 분류·수단을 즉시 안내하고 사용자가 저장할 때 적용합니다. 환불 연결 거래의 날짜·금액·유형은 읽기 전용과 제한 이유를 표시하며 연결 환불 보기로 이동할 수 있습니다. 고정지출 거래 편집에는 '이번 회차만 변경'을 표시합니다. 저장 후 신규는 S-02, 편집은 이전 상세로 복귀합니다.

## 7. S-04 — 환불 등록·수정

- 상단 읽기 전용: 원거래명·원거래일·금액, 기존 환불 합계, 이번 입력의 최대 가능액.
- 입력 순서: 환불일(신규 오늘) → 환불액 → 메모. 수정의 최대액은 수정 중인 환불을 제외해 계산합니다.
- 저장 전 안내: '환불한 날짜의 지출·예산에서 차감됩니다'. 원거래일 이전·미래·0원·누적 초과는 필드 오류입니다.
- 결과: S-02 원거래 상세로 복귀하고 수정한 환불을 강조합니다. 별도 성공 확인창은 사용하지 않습니다.

## 8. S-05 — 통계

- S-01의 내역/통계 보조 탭으로 진입하며 기간·필터를 공유합니다. 필터가 있으면 '필터 적용 통계'라고 표시합니다.
- 위에서부터 요약과 비교 기간 → 일별 수입·순지출 막대 → 최근 12개월 추이 → 카테고리 현황 → 결제수단 현황 순서입니다. 12개월은 선택 종료일이 속한 월까지이며 진행 중인 월을 표시합니다.
- 분류 표: 환불 전 지출·환불·순지출·환불 전 비중. 수단 표에는 확정 지출 횟수도 표시합니다. 미분류·미선택 그룹을 포함합니다.
- 각 차트에 표 전환/데이터 표를 제공합니다. 0 이하 기준값에는 비교 증감률 대신 차액만 표시합니다. 미래 기간만 선택했으면 실제 데이터 없음과 예정액을 구분합니다.
- 분류·수단 행 선택 시 동일 기간에 해당 필터를 추가한 S-01로 이동합니다. 합계에 포함된 실제 기록을 조회할 수 있어야 합니다.

## 9. S-06·S-07 — 월 예산과 설정·복사

**S-06:** 월 이동 → 전체 예산 카드(예산·사용액·잔여액·초과액·사용률) → 고정지출 예정액 → 카테고리 한도 카드. 예산이 없으면 실제 사용액과 '예산 설정'을 표시합니다. 미설정 카테고리도 사용액은 확인할 수 있습니다.

**S-07 설정:** 전체 예산 필수 → 카테고리 추가·한도 입력 → 저장. 0원은 허용합니다. 한도 합계 초과는 경고이며 저장 차단 오류와 시각적으로 구분합니다. 기존 보관 카테고리 한도는 유지·수정·제거할 수 있으나 새로 선택할 수 없습니다.

**복사:** 원본 월 선택 → 전체 금액·활성 한도·제외할 보관 한도 미리보기 → 대상 월 확인 → 기존 설정 덮어쓰기 확인. 취소하면 대상 월을 유지합니다. **삭제:** 해당 월 전체 예산과 한도가 함께 삭제되며 거래는 유지됨을 D-01에 표시합니다.

카드 선택은 해당 월·카테고리의 S-01로 연결합니다. 예산 초과와 음수 순사용액을 숨기지 않고 정책 P-02 계산식대로 표시합니다.

## 10. S-08~S-10 — 저축 목표와 기록

**S-08 목록:** 활성/보관 전환, 목표 추가. 카드에는 목표명·누적액/목표금액·진행률·목표일·진행 중/달성/기한 경과를 표시합니다. 목표일 오름차순·생성일 순으로 정렬합니다.

최신 목록 UI: 보관함 버튼을 제거하고 '나의 저축 목표' 카드 목록 아래에 '완료된 목표' 접기/펼치기 영역을 제공합니다. 기본은 접힘이며 제목에 건수를 표시합니다. 펼치면 완료 목표명·누적액·목표액·달성 상태를 표시합니다. 완료 영역은 달성한 목표를 위한 구분이며 미달성 보관 목표를 완료로 간주하지 않습니다. 퍼블리싱에는 완료 목표 샘플 1개를 표시합니다.

**S-09 상세:** 진행 요약 → 저축/인출 추가 → 날짜별 기록 → 목표 수정·보관/복원·삭제. 기록은 날짜 내림차순이며 저축/인출·금액·메모와 수정·삭제를 제공합니다. 보관 목표는 읽기 전용으로 복원만 활성화합니다. 기록이 있는 목표는 삭제 대신 보관을 안내합니다.

**S-10 목표 입력:** 목표명 → 목표금액 → 시작일(신규 오늘) → 목표일. 목표일은 사용자가 지정합니다. 기존 기록보다 뒤로 시작일을 옮기면 오류를 표시합니다.

**S-10 기록 입력:** 연결 목표 읽기 전용 → 저축/인출(기본 저축) → 날짜(오늘) → 금액 → 메모. 미래 시작 목표는 추가를 비활성화하고 시작일을 안내합니다. 인출 가능액은 단순 현재 잔액으로 저장을 허용하지 않고 이후 날짜까지 검증합니다. 오류에는 처음 음수가 되는 날짜와 부족액을 표시합니다.

기록 삭제는 확인 후 검증합니다. 삭제로 이후 잔액이 음수가 되면 삭제하지 않고 이유를 표시합니다. 목표 변경·기록 변경 후 진행 상태를 다시 계산하며 가계부 거래는 만들지 않습니다.

## 11. S-11~S-13 — 관리와 고정지출

**S-11:** 고정지출·카테고리·결제수단·백업 메뉴, 현재 브라우저 저장 안내. 데이터베이스 ID나 내부 버전은 일반 메뉴에 노출하지 않습니다.

**S-12 목록:** 활성/중지 탭, 이름·기본 금액·주기·다음 예정일·종료일. 삭제된 설정은 일반 목록에 노출하지 않고 기존 거래의 원래 반복 정보로만 표시합니다.

**S-12 상세:** 반복 기본 정보와 수정·중지/재개·삭제 → 조회 기간 선택 → 회차 목록. 회차 행은 원래 회차일, 변경 거래일(다를 때), 금액·상태·개별 수정 표시입니다. 회차 선택은 S-02로 연결합니다.

**S-13 입력:** 내역명 → 기본 금액 → 주기 → 시작일 → 종료일 선택 → 지출 카테고리 → 결제수단 → 메모. 월·년 반복에는 없는 날짜를 말일로 처리한다는 예시를 표시합니다. 과거 시작은 생성 회차 수·합계·기간 미리보기 후 확인받습니다.

- 반복 편집: '미확정 일반 회차에 적용, 확정·개별 수정·건너뜀 유지'와 변경 대상 건수를 표시합니다.
- 중지·삭제: 먼저 도래 거래 처리 결과를 안내하고 앞으로 제거할 예정 회차와 개별 수정 회차 수를 보여줍니다. 무기한 반복은 '이후 모든 회차'라고 표시하며 유한한 전체 건수처럼 표현하지 않습니다. 확정 거래 유지와 삭제 후 재개 불가를 설명합니다.
- 재개: 오늘 이상 재개일 선택, 다음 발생일과 중지 기간 소급 생성 없음 안내. 종료일이 지났으면 먼저 수정으로 연결합니다.
- 확인 중 다른 탭·날짜 변경으로 대상이 바뀌면 새 미리보기를 보여주고 재확인합니다.

## 12. S-14 — 카테고리·결제수단

- 카테고리: 수입/지출 탭과 활성/보관 전환. 이름·유형, 추가·수정·보관/복원·삭제.
- 결제수단: 활성/보관 전환. 이름·6개 유형, 추가·수정·보관/복원·삭제. 신규 유형 기본값은 기타.
- 신용카드 목록·상세에 '결제일 · 매월 N일'을 표시합니다. 설정 폼에서 신용카드 선택 시 선택 입력인 결제일 필드를 제공합니다. 미입력은 미설정, 체크카드는 즉시 출금, 그 외는 해당 없음으로 표시합니다. 실제 휴일 이연 출금일이나 청구액은 계산하지 않습니다.
- 결제수단 선택 시 해당 수단의 내역만 모은 상세를 엽니다. 기간·건수·합계와 거래 목록을 표시하고 각 행에서 거래 상세로 이동합니다. 내역이 없으면 빈 상태를 표시합니다. 현재 퍼블리싱에서는 2026년 11월 샘플 내역을 사용합니다.
- 같은 범위의 이름 중복은 보관 항목까지 검사하고 해당 이름을 안내합니다. 보관 항목과 충돌하면 기존 항목 복원으로 연결합니다.
- 참조 있는 항목 삭제 시 '사용 중이므로 보관할 수 있어요'와 보관 동작을 제공합니다. 참조 없는 항목만 D-01 확인 후 삭제합니다.
- 보관 안내: 기존 내역·예산·반복 연결은 유지하고 새 선택에서 제외됨을 명시합니다. 사용 중 카테고리 유형은 읽기 전용입니다.

## 13. S-15 — 백업·복원

| 단계 | 내용 | 동작 |
| --- | --- | --- |
| 기본 | 브라우저 저장 안내, JSON 내보내기, 파일 선택, 복원 직전 사본(있으면 시각) | 현재 데이터/사본 다운로드 |
| 검증 중 | 선택 파일명·진행 표시 | 취소 가능, 기존 데이터 변경 없음 |
| 검증 실패 | 항목 종류·ID·오류 이유 목록 | 다른 파일 선택, 전체 적용 차단 |
| 미리보기 | 파일 생성일·버전·시간대·통화, 현재/복원 건수·기간, 자동 확정 건수·금액 | 취소 / 전체 대체 확인 |
| 적용 중 | 사본 보존과 전체 대체 진행 표시 | 재실행 차단, 중간 취소 제공하지 않음 |
| 성공 | 복원 건수·자동 확정 결과 | 내역 확인, 사본 다운로드 |
| 실패 | 기존 데이터 유지 안내, 실패 이유 | 재시도·다른 파일 선택 |

미리보기의 최종 버튼은 '기존 데이터를 전체 대체'로 표시합니다. 확인 시점에 데이터 또는 한국 날짜가 바뀌면 미리보기를 다시 보여줍니다. 좁은 화면에서는 건수 비교를 카드로 바꿉니다. 복원 직전 사본도 같은 브라우저에 저장되므로 외부 파일 보관을 대체하지 않음을 안내합니다.

## 14. 화면과 데이터 연결 검증

| 상황 | 연결 결과 |
| --- | --- |
| S-03에서 미래로 날짜 변경 | S-02 예정 표시, S-01 실제 집계 제거, S-06 사용액 갱신 |
| S-04에서 다른 달 환불 저장 | 원거래일 유지, 환불일 S-01·S-06만 차감 |
| S-12 회차 건너뜀 취소 | 해당 거래일 기준 예정/확정, 중복 생성 없음 |
| S-14 항목 보관 | 과거 상세 연결 유지, S-03 신규 선택에서 제외 |
| S-10 저축·인출 저장 | S-08·S-09만 갱신, 내역·예산 변화 없음 |
| S-15 복원 | 모든 화면의 기존 조회 캐시 무효화, 오래된 편집 저장 차단 |

화면별 입력·빈 상태·오류·확인·취소·성공을 모바일과 데스크톱에서 검증합니다. 색상·타이포그래피·간격의 시각 디자인은 이 구조를 기준으로 구현 단계에서 구체화합니다.
- 내역 목록은 별도의 이전 내역 버튼 없이 하단 스크롤에 따라 다음 내역을 이어 표시합니다. 로딩 중과 마지막 내역 상태를 표시하고, 열린 상세와 입력 중인 내용은 유지합니다. 선택 삭제 모드에서는 자동 로딩을 멈추며 전체 선택은 현재 불러온 내역에 적용합니다. 퍼블리싱은 샘플 30건을 12건 단위로 표시합니다.
