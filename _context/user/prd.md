# acco-note 사용자 요구사항 (초안)

> 사용자가 직접 제시한 요구사항을 기록합니다. 구체적인 구현 및 미확정 정책은 추후 논의합니다.

## 1. 서비스 및 데이터 관리

- 로그인 및 회원가입 기능은 제공하지 않습니다.
- 별도의 백엔드 서버 없이 동작하는 웹 기반 가계부로 구성합니다.
- 가계부 데이터는 브라우저의 IndexedDB(IDB)에 저장하고 관리합니다.
- 가계부 데이터를 JSON 형식으로 내보내기(Export) 및 가져오기(Import) 할 수 있어야 합니다.

## 2. 가계부 작성

- 사용자가 날짜별 가계부 내역을 직접 작성할 수 있어야 합니다.
- 각 가계부 내역은 **지출** 또는 **수입** 타입을 선택할 수 있어야 합니다.

## 3. 결제수단 관리

- 가계부 지출 내역에 사용한 결제수단(카드 등)을 기록할 수 있어야 합니다.
- 어떤 결제수단을 얼마나 사용했는지 확인할 수 있어야 합니다.
- 결제수단의 목적은 **실제 결제 처리나 카드 연동이 아닌, 사용 내역 기록 및 분석**입니다.
- 결제수단의 유형과 관리 방식, 통계 세부 항목은 추후 결정합니다.

## 4. 고정지출 관리

- 고정지출 항목을 일반 가계부 내역과 별도로 관리할 수 있어야 합니다.
- 고정지출 항목은 해당 날짜의 가계부 화면에 표시되어야 합니다.
- 고정지출의 자동 내역 반영 여부 및 반복 주기 등 세부 정책은 추후 결정합니다.

## 5. 목표 설정

- 가계부 목표를 설정할 수 있어야 합니다.
- 목표의 종류, 기간 및 달성 기준은 추후 결정합니다.

## 6. 조회 및 데이터 시각화

- 가계부 데이터를 시각화할 수 있어야 합니다.
- 가계부 내역을 **일별**, **주별**, **월별**로 조회할 수 있어야 합니다.
- 시각화 지표와 차트 종류는 추후 결정합니다.
